必要な情報を、
報告までの流れに整える。

既存のExcelや課題管理ツールを置き換えるのではなく、テスト進捗と報告に必要な情報を、ひとつの流れで扱います。

取り込む

Excel・CSV・QualityForward API・TestRail APIの結果を取り込み、列と結果の対応も保存できます。

整える

現場の結果表記を変換し、使う結果と表示名をプロジェクトごとに設定できます。

見える化する

複数計画の日別目標、実績、累計、推移グラフを同じ画面で確認できます。

チケットとつなぐ

Redmine・Jira Cloudの不具合やQAを、テストケースとあわせて確認できます。

報告する

日報・期間報告を作成し、進捗はテキスト・画像でコピーして共有できます。

画面で見る、日々の進捗管理。

計画、テストケース、日報を、同じアプリの中で確認。実務で扱う情報を、見たい粒度で追えます。

ローカル環境で管理。
必要なときだけ外部と連携。

テストデータ、計画、日報はローカル環境に保存します。QualityForward、TestRail、Redmine、Jira Cloudとの通信は、利用者が連携を設定した場合に行われます。

APIキーを保護

OSの暗号化機能で保護します。

初回起動について

ほっほリーダーはローカル環境で動作するアプリです。ダウンロードしたZIPファイルを展開してから起動してください。

Windows

  1. ZIPファイルを展開します
  2. 展開したフォルダ内の「ほっほリーダー.exe」を起動します
  3. Windows Defender SmartScreenが表示された場合は「詳細情報」→「実行」を選択します
