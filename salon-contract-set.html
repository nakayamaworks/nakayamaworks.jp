サロン向け制作・運用契約書類セット

Nakayama Worksがサロンと契約締結するときに使いやすい、A4印刷用の書類ひな形です。

Cover / 01

このセットは、LPに掲載している「公式サイト制作」「予約システム導入支援」「公開後の運用サポート」を前提に構成しています。基本条件は利用規約ページの内容に寄せつつ、紙契約で使えるよう個別記入欄を追加しています。

収録書類
  1. 業務委託基本契約書
  2. 個別契約書兼申込書
  3. 個人情報取扱確認書
  4. 公開・引渡確認書
推奨の使い方
  1. 初回契約時に基本契約書と個別契約書を署名
  2. 予約情報や顧客情報を扱う場合のみ個人情報取扱確認書を添付
  3. 公開時または納品時に公開・引渡確認書で最終確認

記入チェック

  • 甲乙の正式名称、住所、代表者名、連絡先
  • 初期料金、運用プラン料金、第三者サービス費用の負担区分
  • 着手日、初稿確認日、公開予定日、解約予告日数
  • 修正回数、検収方法、引渡対象データの範囲
  • 実績掲載の可否、個人情報の取扱範囲、アカウント引渡先

料金欄の初期値

LP記載の基準料金は、初期料金 30,000円、運用プラン料金 ライト 5,000円/月・スタンダード 10,000円/月・運用代行 15,000円/月 です。予約通知のSMS通知オプションは +2,000円/月 を初期入力の参考値としています。

印刷メモ

  • A4 / 縦 / 片面印刷推奨
  • ブラウザ印刷時はヘッダー・フッター表示をオフ
  • コンビニ印刷へ回す場合は、先にPDF保存してからアップロード
  • 紙契約で署名押印する前に、印紙要否と最終文言を確認

第1条（目的）

本契約は、甲が乙に対して提供する公式Webサイトの企画・制作、予約システム導入支援、公開後の運用サポートその他これらに付随する業務について、基本的な条件を定めることを目的とする。

第2条（対象業務）

  1. 甲が提供する具体的な業務内容、納期、料金、修正回数、引渡物、サポート範囲等は、別途締結する個別契約書兼申込書に定める。

  2. 本契約における「月」とは、毎月1日から末日までの暦月をいう。

    甲は、乙の要望に基づき、サイト構成、デザイン、HTML/CSS実装、公開支援、予約システム設定支援等を行う。

    運用プランに含まれる対応範囲は、ライトプラン、スタンダードプラン、運用代行プランの別および個別契約の定めに従う。各プランには、公式サイトおよび予約システムの継続利用、LINEチャットによる相談対応、軽微修正、更新代行、設定変更その他甲が定める運用支援のうち、該当プランに応じた範囲を含む。

  3. 前項の上限を超える対応、新規ページ作成、構成変更、レイアウト変更、バナー制作、予約導線の変更、機能追加その他軽微な更新又は相談対応の範囲を超える対応は、別途見積りのうえ有償で行う。
  4. 甲は、集客数、売上、検索順位、予約件数その他の事業成果を保証しない。ただし、乙の目的達成に向けて、個別契約および運用プランの範囲内で改善提案および運用支援を行う。

第3条（個別契約の成立）

  1. 個別案件は、乙による申込みと甲による承諾により成立する。
  2. 個別契約が本契約と抵触する場合、個別契約の定めが優先する。
  3. 乙に虚偽記載、反社会的勢力との関係その他甲が不適当と判断する事由がある場合、甲は申込みを承諾しないことができる。

第4条（乙の協力義務）

  1. 乙は、制作に必要な文章、画像、ロゴ、メニュー情報、価格、店舗情報、予約運用情報等を、甲が指定する期限までに提供する。
  2. 乙は、提供素材について第三者の権利を侵害しないことを保証し、紛争が生じた場合は自己の責任と費用で解決する。
  3. 乙の確認遅延、素材未提出、仕様変更その他乙の事情により、納期は甲が乙へ通知した変更後の期日まで延長されることがある。

第5条（確認・修正）

  1. 甲は制作工程において必要に応じてレビューを依頼し、乙は甲が指定する期限までに確認と回答を行う。
  2. 基本修正回数は3回までとする。ここでいう「1回の修正」とは、甲が乙に対して確認依頼として送付した各制作物又は確認用画面一式に対し、乙が1回にまとめて提出する修正指示一式をいう。乙が同一の確認依頼に対する修正指示を複数回に分けて送付した場合、分割された各回はそれぞれ1回の修正として扱うものとする。
  3. レイアウトの全面見直し、ページ構成の変更、デザイン方針の変更、新規素材の大量追加、予約導線の再設計、機能追加その他これに準ずる大幅変更は、前項の基本修正に含まれず、別途見積りとする。
  4. 乙が公開前の確認を完了した後に生じた再修正は、軽微な誤記修正を除き追加対応とする。

第6条（料金・支払い）

  1. 乙は、個別契約で定める初期料金、運用プラン料金、追加対応費用その他の対価を、定められた支払期日までに支払う。
  2. 個別契約に別段の定めがない場合、初期料金は申込時又は甲が指定する初回決済時に支払うものとし、運用プラン料金は利用開始日を基準として各利用期間の開始時に前払いで支払うものとする。初回は、初期料金と初月分の運用プラン料金をまとめて支払うことができる。Stripeによる自動決済を利用する場合、2回目以降の運用プラン料金は当該基準日に毎月自動で決済する。
  3. 支払方法は銀行振込、Stripe決済、現金その他双方が合意した方法とし、振込手数料は乙の負担とする。
  4. 乙が支払いを遅延した場合、甲は業務の一時停止、公開作業の延期、アカウント管理の停止または契約解除を行うことができる。
  5. 第三者サービスの利用料、決済手数料、ドメイン費用、サーバー費用等は、個別契約に別段の定めがない限り乙の負担とする。

第7条（納品・検収）

  1. 甲は、個別契約で定める方法により制作物又は設定完了状態を乙へ提示し、乙は納品日又は公開確認依頼日のいずれか遅い日から7日以内（以下「検収期限」という。）に、検収結果を具体的な修正指摘又は不承認理由とともに通知する。
  2. 乙から検収期限内に個別契約および第5条に定める範囲内の修正指摘があった場合、甲は当該範囲内で対応する。
  3. 乙が検収期限内に修正指摘又は不承認理由を通知しない場合、当該制作物は検収完了したものとみなす。
  4. 検収完了後に発見された不具合又は追加要望については、第5条および個別契約の定めに従い、内容に応じて運用プラン又は別途有償対応とする。

第8条（知的財産権）

  1. 本条における「成果物」とは、個別案件のために甲が新規に制作したHTMLファイル、CSSファイル、当該案件専用に作成した画像データ、テキストデータ及びこれらに付随する納品データをいう。ただし、甲又は第三者が従前から保有するテンプレート、ライブラリ、フォント、写真素材、ノウハウ、汎用コード、設計思想、運用手法等は成果物に含まれない。乙が対価を完済した後、成果物の著作権は乙に移転する。
  2. 甲が従前から保有するテンプレート、ライブラリ、ノウハウ、汎用部品、設計思想、運用手法その他再利用可能な資産に関する一切の権利は、甲に留保される。
  3. 乙は、成果物を自己の事業目的の範囲で利用できるが、甲に留保されたテンプレート、ノウハウ、汎用コードその他再利用可能な資産を第三者へ再配布、転売又は流用してはならない。

第9条（第三者サービス）

  1. 甲は、Google、GitHub Pages、みせまるクラウド、Stripeその他の外部サービスを利用することがある。
  2. 外部サービスの仕様変更、提供停止、障害、料金改定、セキュリティ事故等に起因して乙に損害が生じた場合、甲は自己の故意または重過失がある場合を除き責任を負わない。
  3. 乙名義で契約または管理すべきアカウントは、原則として乙が契約主体となる。

第10条（秘密保持）

  1. 甲および乙は、相手方から秘密として開示された技術上、営業上、運営上その他一切の非公開情報を、相手方の事前承諾なく第三者へ開示または漏えいしてはならない。
  2. 前項の義務は、法令に基づく開示、公知情報、開示前から保有していた情報、正当な権限を有する第三者から適法に取得した情報には適用しない。
  3. 本条の義務は、本契約終了後も3年間存続する。

第11条（実績掲載）

  1. 甲は、サイト名、URL、トップページ画像、ロゴその他公開済み情報を制作実績としてWebサイト、提案資料、SNS等に掲載できる。
  2. 乙が掲載を希望しない場合、個別契約でその旨および非掲載とする範囲を指定することにより、甲は当該指定の範囲で掲載を行わない。

第12条（個人情報の取扱い）

  1. 甲は、乙または乙の顧客に関する個人情報を、問い合わせ対応、予約システム設定、データ移行、運用サポートその他本業務の遂行に必要な範囲でのみ利用する。
  2. 甲は、個人情報の漏えい、紛失、改ざん等を防止するため、合理的な安全管理措置を講じる。
  3. 甲が乙の顧客情報に直接アクセスする場合は、必要に応じて本契約に加え「個人情報取扱確認書」を作成する。

第13条（契約期間・解約）

  1. 本契約は締結日から有効とし、いずれか当事者が終了を申し出るまで存続する。ただし、個別案件の具体的な期間は個別契約に定める。
  2. 本条における「任意解約」とは、債務不履行その他の法定又は約定解除事由によらず、当事者の都合により将来に向かって本契約又は個別契約を終了させることをいう。運用プランの最低契約期間は利用開始日から6か月とし、7か月目以降の任意解約は月末締めとする。乙は、解約希望月の前月末日までに、書面又は電子メールで甲へ通知する。
  3. 乙は、運用プランの最低契約期間中であっても、ライトプラン、スタンダードプランおよび運用代行プランの相互変更を希望することができる。プラン変更は、適用希望月の前月末日までに乙が甲へ通知し、原則として翌月1日から適用する。
  4. 前項に基づく任意解約が成立した場合でも、甲は当該解約月の末日まで個別契約に定めるサービスを提供し、乙は当該月末日までの料金を支払う。運用プラン終了後は、甲が管理する公式サイトおよび予約システムは継続利用できないものとし、継続利用を希望する場合は別途協議する。
  5. 乙が制作開始後に個別案件を任意解約し、又は乙の都合により中断した場合、甲は、作業完了部分に相当する費用、既に確保又は手配済みの外注費、素材費、交通費その他実費を請求できる。
  6. 甲又は乙が本契約又は個別契約に違反し、相手方が書面又は電子メールにより催告した後7日以内に是正しない場合、相手方は本契約又は当該個別契約の全部又は一部を解除できる。

第14条（責任制限）

  1. 甲の責に帰すべき事由により乙へ損害が生じた場合、甲の賠償責任は、直近3か月間に甲が受領した本サービスの対価総額を上限とする。ただし、甲に故意または重過失がある場合を除く。
  2. 甲は、逸失利益、間接損害、特別損害について責任を負わない。
  3. 天災地変、火災、停電、通信回線障害、インターネット障害、ドメイン又はDNS障害、サーバ障害、法令改正、感染症の流行、行政上の措置その他甲の合理的支配を超える不可抗力により生じた履行遅滞又は履行不能について、甲は責任を負わない。
  4. Google、GitHub、みせまるクラウド、Stripeその他外部サービスの仕様変更、障害、停止、制限、アカウント凍結、料金改定その他当該外部サービスに起因する事象については、甲の故意又は重過失がある場合を除き、甲は責任を負わない。

第15条（反社会的勢力の排除）

  1. 甲および乙は、自らまたはその役員等が反社会的勢力に該当せず、また将来にわたっても関与しないことを表明し保証する。
  2. 相手方が前項に違反した場合、催告なく直ちに本契約および個別契約を解除できる。

第16条（協議・管轄）

  1. 本契約に定めのない事項または解釈に疑義が生じた場合、甲乙は誠実に協議して解決する。
  2. 本契約に関する訴訟については、甲の主たる事務所所在地を管轄する地方裁判所または簡易裁判所を第一審の専属的合意管轄裁判所とする。
