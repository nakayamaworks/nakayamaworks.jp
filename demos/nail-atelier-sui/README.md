# Nail Atelier SUI デモサイト仕様書

## 0. デザイン選定
- 第1候補は `Vintage` です。
- 理由:
  - ネイルの繊細さと相性がよく、手元写真を主役にしやすい
  - `Luxury` ほど重くならず、`Cute` ほど対象を狭めすぎない
  - 既存の `青葉整体院`（Basic）、`Salon de ÉCLAT`（Luxury）、`Organic Hair Salon LINO`（Natural）と世界観が被りにくい
  - 地元密着の上品な個人サロンという設定に落とし込みやすい

## 1. 目的
- 本フォルダは、営業用ポートフォリオとして使用するネイルサロンのデモサイトです。
- 目的は「Nakayama Works は美容系でも、派手さに頼らずブランドの空気感を丁寧に設計できる」ことを示すことです。
- ブランド名は `Nail Atelier SUI` とします。

## 2. 対象範囲
- 対象パス: `nakayama_works_lp/demos/nail-atelier-sui/`
- 主要ファイル（想定）:
  - `index.html`
  - `i18n-demo.js`
  - `images/`

## 3. テンプレートコンセプト
### Vintage Atelier Template
「日々の所作を、静かにきれいに整える」

- ネイルを“盛る”より“整える”体験として見せる
- 写真は手元の質感、空間の温度、施術の丁寧さを優先
- カフェのような落ち着きと、アトリエのような私的感を共存させる
- 予約を急かさず、作品と空気感で自然に興味を育てる

## 4. ブランド設定
- ブランド表記:
  - 1行目: `Nail Atelier`
  - 2行目: `SUI`
- ブランドコピー:
  - `指先に、静かな余白を。`
- 想定ターゲット:
  - 20代後半〜40代女性
  - 派手なアートより、ニュアンス・ヌーディ・上品系を好む層
  - 落ち着いた個人サロンを探しているユーザー

## 5. デザイン方針
- キーワード: `Warm` / `Refined` / `Vintage` / `Calm` / `Craft`
- ビジュアル:
  - アイボリー / ミルクベージュ / ブラウン / ダークグリーン
  - 紙、木、リネン、陶器のようなやわらかい質感
  - 直線をベースにしつつ、角は少しだけ丸める
  - 写真は手元の寄り、施術道具、店内の一角を静かに切り取る
- 禁止事項:
  - 強いピンク
  - ラメ感の強いキラキラ演出
  - 過剰なガーリー装飾
  - 黒金ベースのラグジュアリー表現

## 6. タイポグラフィ
- 欧文ロゴ・見出し: `Cormorant Garamond`
- 和文見出し: `Zen Old Mincho`
- 本文: `Noto Sans JP`
- 可読性は保ちつつ、少し文学的な余韻が残る組版を目指します。

## 7. ページ構成（SUI専用）
- Opening（任意）
  - 生成りの背景にロゴを静かに表示
  - 数秒でヒーローへ遷移
- Hero
  - 手元の寄り写真を大きく使用
  - コピーは最小限
  - 表示文言:
    - `Nail Atelier`
    - `SUI`
    - `指先に、静かな余白を。`
- Concept
  - サロンの思想を短い文章で伝える
  - 「丁寧なケア」「肌になじむ色」「静かに過ごせる時間」を軸に構成
- Design Lineup
  - `Nuance`
  - `Nude`
  - `Bridal`
  - `Care`
  - カードよりもルックブック寄りの見せ方を優先
- Gallery
  - ネイル作品を主役にしたグリッド
  - 手元のアップと全体カットを混ぜてリズムを作る
  - クリックで拡大
- Salon Story
  - 店内の一角、素材、道具、施術風景を掲載
  - 「この空間で過ごす時間」を想像できる構成
- Stylist
  - 1名または2名
  - 経歴よりも人柄と施術スタンスを短く見せる
- Menu
  - 価格表を詰め込みすぎず、代表メニューに絞る
  - 例:
    - ニュアンスデザイン
    - ワンカラー
    - ハンドケア
    - ブライダルネイル
- Flow
  - 予約から来店までの流れを簡潔に表示
- Access
  - 住所 / 営業時間 / アクセス / 支払い方法
- Reservation
  - 最下部でCTAを表示
  - 空気感を壊さない落ち着いたボタンにする

## 8. UX・アニメーション仕様
- 基本思想: 「ページをめくるような静かな移動」
- スクロール演出:
  - フェード + 上下 `8px`〜`16px`
  - `0.5s`〜`0.9s` の短すぎない遷移
  - 作品写真は少し遅れて出す
- ホバー演出:
  - 画像の拡大はごく控えめ
  - ボタンは色ではなく明度差で反応させる
- モバイル:
  - 下部固定CTAは必須ではない
  - 作品閲覧と予約の邪魔をしない情報密度を優先

## 9. モーダル仕様
- Gallery Lightbox:
  - 画像拡大
  - 前後ボタン
  - キーボード矢印対応
  - スワイプ対応
- Menu Detail Modal（任意）:
  - 所要時間
  - 施術内容
  - おすすめの来店シーン

## 10. 予約導線仕様
- 表示箇所:
  - ナビ内に小さく1つ
  - 最下部CTAに1つ
- 予約導線のトーン:
  - 押しの強いコピーは使わない
  - `空き状況を見る` や `ご予約はこちら` 程度に留める
- 予約先URL（想定 `index.html` 内）:
  - `const RESERVE_BASE_URL = 'https://misemaru.cloud/jp/nail_atelier_sui/';`
- リンク付与パラメータ:
  - `lang`
  - `return`

## 12. 画像方針
- 最優先:
  - 手元の自然な質感
  - くすみカラー、ヌーディカラー、ニュアンス系
  - 木、布、紙、陶器、小物
  - やわらかい自然光
- 禁止:
  - スタジオ感の強い白飛び写真
  - 派手なストーンやギラつき中心のカット
  - 世界観に対して若すぎるポップ演出

## 13. SEO / パフォーマンス方針
- `h1` はヒーロー内で1つに統一
- 作品画像は一覧では `loading="lazy"` を基本
- 重いライブラリは使わず、素のJS + CSSを基本とする
- モバイルでの作品閲覧体験を優先し、画像最適化を重視する

## 14. この方向を選ぶ理由
- ネイルサロンは `Cute` や `Luxury` に寄せやすいが、営業用ポートフォリオとしては表現の幅が狭く見えやすいです。
- `Vintage` にすると、ネイル特有の繊細さを保ちつつ、暮らし・空間・手仕事の文脈まで含めて提案できます。
- 既存3デモとの並びでも、世界観の差が一目で伝わりやすくなります。
